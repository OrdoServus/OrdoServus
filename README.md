# ⛪ [OrdoServus](https://ordoservus.vercel.app)
**Der digitale Begleiter für Liturgie und Pastoral.**

> OrdoServus ist eine Open-Source-Webanwendung, die speziell für Pfarrer, Diakone und 
> pastorale Mitarbeiter entwickelt wurde. Sie kombiniert eine strukturierte 
> Gottesdienst-Planung mit einem flexiblen Notizbuch.

![License](https://img.shields.io/github/license/ordoservus/ordoservus)

## Funktionen

- **Digitales Notizbuch:** Organisation in Registern.
- **Digitaler Kalender:** Ein Kalender für das Planen von Gottesdiensten.

### Security

Sollten Sie ein Sicherheitsproblem identifiziert haben, erstellen Sie bitte nicht direkt ein Issue oder einen PullRequest, damit die Schwachstelle nicht ausgenutzt wird.

Befolge bitte die Anweisungen in den [Sicherheitshinweise](/SECURITY.md)

# Developing and contributing

Wir möchten euch darüber informieren, dass Träwelling ein Freizeitprojekt ist, das von einem Team ehrenamtlicher Helfer in ihrer Freizeit entwickelt und betreut wird. 
Wir geben unser Bestes, Probleme zu beheben und die Plattform zu verbessern, bitten euch aber um Verständnis, dass wir nicht immer sofort auf Anfragen reagieren können. Wir freuen uns jedoch über jeden, der zum Projekt beitragen möchte! 
Wenn ihr einen Fehler findet oder eine Idee für eine neue Funktion habt, könnt ihr gerne ein Issue/eine Diskussion auf GitHub eröffnen. 
Wir ermutigen euch ausserdem, uns zu unterstützen, indem ihr selbst Fehler behebt und neue Funktionen implementiert.

Weiteres findest du in den [contributing guidelines](/CONTRIBUTING.md).
